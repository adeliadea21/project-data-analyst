# Project Data Analyst

Project ini merupakan repositori untuk analisis data yang berfokus pada proses cleaning data dan visualisasi hasil analisis dalam bentuk dashboard. Tujuan utama dari project ini adalah mengubah data mentah menjadi informasi yang lebih rapi, terstruktur, dan mudah dipahami melalui analisis dan presentasi data.

## Deskripsi Project

Project ini dibuat untuk:
- membersihkan dataset dari data yang tidak valid, duplikat, atau tidak konsisten
- melakukan eksplorasi data untuk menemukan pola dan insight penting
- mempersiapkan data agar siap digunakan untuk analisis lebih lanjut
- menyajikan hasil analisis dalam bentuk dashboard atau laporan singkat

## Tujuan

- Meningkatkan kualitas data sebelum analisis
- Mempermudah interpretasi hasil analisis
- Menyediakan struktur project yang rapi dan mudah dikembangkan
- Membantu pengambilan keputusan berdasarkan data

## Struktur Repository

```text
project-data-analyst/
├── README.md
├── data/
│   └── data_cleaning/
│       └── dashboard/
│           └── readme.md
```

## Folder dan Isi

### `data/`
Folder ini berisi data yang digunakan dalam project, termasuk data mentah dan data hasil cleaning.

### `data/data_cleaning/`
Folder ini mencakup proses cleaning data, seperti validasi, penghapusan duplikasi, normalisasi format, dan penyesuaian nilai data agar lebih konsisten.

### `data/data_cleaning/dashboard/`
Folder ini berisi hasil visualisasi atau dokumentasi dashboard terkait analisis data.

## Workflow Project

1. Mengumpulkan data mentah
2. Melakukan pembersihan data (data cleaning)
3. Mengecek kualitas data dan mencari anomali
4. Melakukan analisis eksploratif
5. Membuat insight dan visualisasi
6. Menyajikan hasil dalam dashboard atau laporan

## Tools yang Digunakan

Project ini dapat dikembangkan menggunakan tools seperti:
- Python
- Pandas
- Jupyter Notebook
- Excel / CSV
- SQL (opsional)
- Power BI / Tableau / Looker Studio (jika dashboard dibuat lebih lanjut)

## Cara Menggunakan

1. Clone repository ini:

```bash
git clone https://github.com/adeliadea21/project-data-analyst.git
```

2. Masuk ke folder project:

```bash
cd project-data-analyst
```

3. Buka dataset yang tersedia di folder `data/`
4. Jalankan proses cleaning dan analisis sesuai kebutuhan
5. Lihat hasil visualisasi di folder `data/data_cleaning/dashboard/`

## Catatan

Project ini masih dalam tahap pengembangan, dan struktur repository dapat disesuaikan seiring dengan bertambahnya file analisis, notebook, atau dashboard baru.
